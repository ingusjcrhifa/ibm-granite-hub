## Overview

IBM Granite Session Hub is a desktop companion for IBM Granite open-source language models, providing a session-based prompt and response management interface, parameter tuning controls for temperature and sampling, model comparison between Granite variants, and conversation export for enterprise documentation workflows.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **IBM Granite Session Hub** delivers the features you need in a clean, intuitive package.

> Official website: [ibm.com](https://ibm.com)

## Key Features

| Feature | Description |
|---------|-------------|
| **Session Management** | Organize prompts and responses into named project sessions |
| **Parameter Tuning** | Adjust temperature, top-p, and max tokens per request |
| **Model Comparison** | Run prompts against multiple Granite model sizes side by side |
| **Export** | Export full session transcripts as Markdown or JSON for documentation |
